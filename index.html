TAFA OTG

TAFA OTG is a personal, manually triggered stock research report tool. Its owner enters one ticker in a private GitHub Actions workflow. The tool reads the owner's existing technical and financial data files from Google Drive, creates a table-focused HTML report, and saves that report in the owner's Google Drive.

The tool does not trade securities, collect new market data, or run on a schedule. Reports are for research only and can contain disclosed data gaps.

Google Drive access is requested so the tool can read its input files and create the result in the owner's Drive. The current integration uses the Google Drive full-access OAuth scope because the existing folder and file workflow needs to locate and write files in the owner's My Drive. Only the owner is intended to authorize this app.
