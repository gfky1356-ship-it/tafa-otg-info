TAFA OTG Privacy Policy

Last updated: 9 November 2026

TAFA OTG is a personal tool used by its owner. It accesses Google Drive only after the owner grants OAuth permission.

Data accessed and purpose

For the ticker entered by the owner, the tool reads existing technical-analysis cache files, financial-analysis source files, and folder metadata from the owner's Google Drive. It uses these files to build one stock research report and writes that HTML report into the owner's Google Drive. It does not read Gmail or Google account contacts.

Storage and processing

The tool runs in the owner's private GitHub Actions repository. Input files are downloaded to the temporary workflow runner and processed there. The runner's temporary files are removed when the job ends. The resulting report remains in the owner's Google Drive until the owner removes it. An OAuth refresh credential is stored locally on the owner's Mac and as an encrypted GitHub Actions secret in the owner's private repository. GitHub workflow logs record the selected ticker, execution status, and resulting Drive link; they are visible to people with access to that private repository.

Sharing

TAFA OTG does not sell, advertise with, or independently share the owner's Google Drive data. Google provides Drive storage and OAuth access, and GitHub hosts the private workflow that processes the files. The owner controls repository access and Google Drive sharing permissions.

Control and contact

The owner can revoke the app's Google access in Google Account settings, remove the GitHub Actions secret, or delete reports from Google Drive. Questions: gfky1356@gmail.com.
